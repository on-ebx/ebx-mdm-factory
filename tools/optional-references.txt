# behind a LinkageError guard (the Factory's Addon* / Mame* wrappers, Connectors' MameGoldenRecords). A class NOT listed here that names an add-on
# class fails the delivery gate: either guard it and list it with the reason, or stop using the add-on there.
# Format: <fully qualified outer class name> then, after whitespace, the reason. Inner classes (Name$1) are covered by their outer class.

com.on.ebx.factory.ebx.AddonMameSuspectDecision     Match and Merge suspect decision, same guard
com.on.ebx.factory.ebx.MameMatchingApi              the facade that catches LinkageError when the add-on is absent
